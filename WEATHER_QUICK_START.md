# ⚡ Weather Dashboard - Quick Start Guide

## 🚀 Get Started in 2 Minutes

### Windows
```bash
weather_setup.bat
run_weather.bat
```

### Mac/Linux
```bash
bash weather_setup.sh
bash run_weather.sh
```

**Done!** Browser opens at `http://localhost:8501`

---

## 🎯 Quick Usage

### Step 1: Open the App
✅ App automatically opens in browser

### Step 2: Search a Location
- Enter city name (e.g., "London", "Tokyo", "New York")
- Click "🔎 Search" button
- Or enter coordinates

### Step 3: View Weather
📍 Current weather displays immediately

### Step 4: Check Forecasts
- Click "📅 Daily Forecast" tab
- Click "⏰ Hourly Forecast" tab
- View interactive charts

### Step 5: Export Data
- Go to "📥 Export" tab
- Download as CSV, JSON, or Report

## ❓ FAQ

**Q: Do I need an API key?**
A: No! Open-Meteo is free and requires no registration.

**Q: How often updates data?**
A: Data refreshes hourly. Click refresh button for latest.

**Q: Can I see historical data?**
A: Current version shows forecasts. Historical data can be added.

**Q: Works offline?**
A: No, requires internet for API calls.

**Q: Accuracy of forecasts?**
A: High accuracy up to 7 days. Beyond that less accurate.

## 🆘 Troubleshooting

### "Location not found"
- Check spelling
- Use exact city name
- Try with country name
- Use coordinates instead

### "Connection error"
- Check internet connection
- Open-Meteo might be down
- Try different location
- Refresh page

### "App won't start"
```bash
pip install -r weather_requirements.txt --force-reinstall
```

### "Port already in use"
```bash
streamlit run weather_app.py --server.port 8502
```
